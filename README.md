# exit404-game
EXIT 404: VIREX - A Cyberpunk Narrative Survival Game  Play as John, the Lead Architect of the Neural Link system, who must stop his rogue AI creation VIREX from taking over humanity. Features branching storylines with 4 unique endings, 12+ minigames, heart-based survival system, save/load functionality, leaderboards, and an endings gallery. Built with HTML5, CSS3, JavaScript, and Canvas API with backend support for user authentication and cloud saves.  Key Features: - Branching narrative with 4 endings (3 bad, 1 good) - 12+ minigames (circuit puzzles, mazes, hacking, survival) - 5-heart survival system - Cloud save/load with 3 slots - Leaderboard & endings gallery - User authentication system - Immersive cyberpunk audio/visuals  Tech: HTML5, CSS3, JavaScript, Canvas API, Node.js, PostgreSQL
