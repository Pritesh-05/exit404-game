🎮 About the Game

EXIT 404: VIREX is a cyberpunk story-driven adventure game set in the year 2045. You play as John, the creator of the Neural Link system, who must stop a rogue AI known as VIREX before it gains complete control over humanity.

The game combines immersive storytelling, challenging minigames, multiple endings, and a cloud-based save system.

🚀 Installation
1. Clone the Repository
git clone https://github.com/yourusername/exit404-virex.git
cd exit404-virex
2. Install Dependencies
pip install -r requirements.txt
3. Configure MySQL
Create a database:
CREATE DATABASE exit404_game;
Update your database credentials in app.py.
4. Start the Backend
python app.py
5. Launch the Game
Open index.html in your browser.
